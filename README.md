# 컴퓨터활용능력 실기 채점 사이트 클론 프로젝트 (Vibe Coding Starter)

제공해주신 사이트 화면(도서 목록 메인 화면, 상세 채점 및 분석 화면, 문제파일 다운로드 모달, 점수별 통계보기 파이차트 모달 등)을 1:1 클론한 웹 프로젝트 뼈대입니다.

---

## 📁 프로젝트 구조

```text
c:\agapp_project\com\
├── index.html       # 메인 진입점 (홈 뷰, 상세 채점 뷰, 모달 3종 포함)
├── css/
│   └── style.css    # 원본 사이트 디자인 시스템 (그리드, 버튼, 배너, 테이블, 반응형)
├── js/
│   ├── data.js      # 교재 목록, 회차 목록, 더미 감점 데이터, 순위/통계 데이터
│   └── app.js       # 화면 전환, 채점 시뮬레이션, Chart.js 인터랙티브 차트 제어
└── assets/          # 이미지 및 정적 리소스용 폴더
```

---

## 🚀 실행 방법

별도의 설치(Node.js, npm 등) 없이 브라우저에서 즉시 열어볼 수 있습니다:

1. 탐색기에서 `c:\agapp_project\com\index.html` 파일을 더블클릭하여 Chrome, Edge 등의 브라우저로 엽니다.
2. 상단 네비게이션:
   - `🏠 채점프로그램 Home`: 메인 도서 목록 화면으로 전환
   - `📂 출판사 자료실`: 영진닷컴 수험서 도서 자료실 페이지로 전환 (1:1 클론)
   - `📋 2급 실기 채점기준`: 컴퓨터활용능력 2급 실기 배점 및 부분점수 기준 모달
   - `💡 도움말 & FAQ`: 이용 안내 팝업 모달
3. 메인 화면:
   - 2027년도/2026년도 교재 목록 및 준비중 카드 렌더링
   - 교재 패널의 **[🌸 출판사 자료실]** 클릭 시 영진닷컴 자료실 화면으로 즉시 전환
   - 교재 카드의 **[채점하기]** 클릭 시 해당 교재의 상세 세부화면으로 즉시 이동
4. 출판사 자료실 화면:
   - 영진닷컴(Youngjin.com) 공식 도서 자료실 1:1 클론 레이아웃
   - 2027/2026/2025 최신 컴퓨터활용능력 1급·2급 실기/필기 도서 부록 예제 및 정답·해설 목록 (게시물 20건)
   - 도서명, 도서코드, 작성자 실시간 검색 필터링
   - 첨부파일(💾) 클릭 시 부록 및 정답자료 다운로드 시뮬레이션
   - `[🏠 채점프로그램 Home으로 돌아가기]` 및 하단 실기 채점하러 가기 배너 제공
5. 상세 채점 화면:
   - 상단 컴활 2급 실기 채점 기준(100점 만점 / 70점 이상 합격) 배너 및 배점 칩
   - 회차 선택 드롭다운 (대표기출, 상시기출 1~10회, 기출유형 1~7회 등)
   - **[해당회차 다운]** 클릭 시 문제파일 다운로드 모달(액세스/엑셀) 노출
   - 파일 업로드 및 **[채점시작]** 클릭 시 실시간 채점 애니메이션, 상세 점수 계산, 합격/불합격 판정 뱃지 갱신
   - 감점 내역 테이블에 문항별 부분점수 기준 표기
   - **[📊 점수별 통계보기]** 클릭 시 회차별/문제별 파이차트 모달 노출
   - 하단 학생/선생님 누적 순위 가로 막대 차트 실시간 렌더링

## 🎨 바이브 코딩(Vibe Coding) 확장 가이드

- **교재 추가 및 변경**: `js/data.js`의 `books2027`, `books2026` 배열에 객체를 추가하기만 하면 자동으로 카드가 렌더링됩니다.
- **채점 로직 연동**: `js/app.js`의 `runGradeSimulation()` 함수를 백엔드 API 호출(Fetch)로 교체하면 실제 실기 채점 서버와 연동할 수 있습니다.
- **스타일 커스텀**: `css/style.css`의 CSS 변수(`:root`)를 조정하여 색상 테마를 쉽게 바꿀 수 있습니다.
